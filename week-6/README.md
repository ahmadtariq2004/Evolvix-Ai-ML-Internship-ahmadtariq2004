# Scribble2Num

Scribble2Num is a local handwritten-number recognition app. Draw a number in the Streamlit sketchpad or upload an image; OpenCV segments the digits and a TensorFlow/Keras CNN predicts each one from left to right.

## Features

- Interactive 600 × 200 drawing canvas with brush and background presets
- Image upload for handwritten numbers
- OpenCV grayscale, blur, Otsu thresholding, and external-contour segmentation
- Left-to-right digit sorting and 28 × 28 MNIST-style input preparation
- Batched single-digit CNN inference and reconstructed number output
- Annotated image with bounding boxes, digit labels, and confidence scores
- Per-digit confidence breakdown
- Local training from the provided image folders; no remote dataset download

## Project layout

```text
.
├── app.py
├── train.py
├── digit_cnn.keras             # Generated by training; included if already trained
└── MNIST Dataset/
    ├── trainingSet/
    │   └── trainingSet/
    │       ├── 0/
    │       ├── 1/
    │       └── ... 9/
    └── trainingSample/
        └── trainingSample/
            ├── 0/
            ├── 1/
            └── ... 9/
```

Each digit folder should contain image files. `train.py` prefers `trainingSet/trainingSet` and falls back to `trainingSample/trainingSample` if needed. The default dataset root is `MNIST Dataset` beside the Python files.

## Install dependencies

On Windows, install the compatible package versions with:

```powershell
py -m pip install "numpy==1.26.4" "tensorflow==2.15.0" "opencv-python==4.11.0.86" "streamlit==1.59.2" "streamlit-drawable-canvas==0.9.3" pillow
```

TensorFlow 2.15 requires NumPy 1.x. The pinned OpenCV and drawable-canvas versions avoid known dependency/API incompatibilities with this setup.

## Train the model

From the project directory:

```powershell
py train.py
```

Training uses a 15% validation split, defaults to 12 epochs and a batch size of 128, and saves the model as `digit_cnn.keras` beside `train.py`.

Optional arguments:

```powershell
py train.py --epochs 16 --batch-size 128
py train.py --data-dir "D:\Datasets\MNIST Dataset" --output "D:\Models\digit_cnn.keras"
```

If a model file already exists, retraining replaces it at the selected output path.

## Start the dashboard

```powershell
py -m streamlit run app.py
```

Streamlit prints the local URL, usually `http://localhost:8501`.

## Use the app

1. Choose **Interactive Sketchpad** or **Upload Image** in the sidebar.
2. For the sketchpad, write digits left to right and leave a small gap between adjacent digits.
3. For uploads, use a clear image containing one handwritten number with good contrast.
4. Review the reconstructed number, average confidence, annotated contour preview, and per-digit breakdown.

The CNN classifies one digit at a time. OpenCV uses external contours to separate digits, so touching digits may be detected as one shape. Leave visible spacing between digits for more reliable segmentation. For very long numbers, use an uploaded image with enough resolution and spacing.

## Troubleshooting

- **Model is not available:** run `py train.py`; the dashboard expects `digit_cnn.keras` in the project directory by default.
- **TensorFlow fails to import:** confirm that the active Python uses TensorFlow 2.15 and NumPy 1.26.4, then restart Streamlit.
- **Drawing canvas is missing:** install `streamlit-drawable-canvas==0.9.3` into the same Python installation used to start Streamlit.
- **Digits are missed or joined:** increase spacing, use a darker stroke, and avoid tiny or low-contrast marks.

All image preprocessing and inference run locally in the app process.
